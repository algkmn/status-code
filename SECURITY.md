# Security Policy

## Supported Versions

Security fixes are provided for the latest version published on Firefox Add-ons.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use the repository's private [security advisory form](https://github.com/algkmn/status-code/security/advisories/new). If that is unavailable, email algkmn@gmail.com with the subject `StatusCode security report`.

Include the affected version, reproduction steps, expected impact, and any proof-of-concept material. Reports should receive an initial acknowledgement within three business days. Confirmed issues will be investigated, fixed, and disclosed in coordination with the reporter.

## Scope

Relevant reports include permission abuse, unexpected data persistence or transmission, unsafe archive contents, remote-code execution, dependency compromise, cross-navigation state leakage, and ways for a noncommitted request to misrepresent the active page.

Automated scanner output without a reproducible security impact may receive lower priority.
